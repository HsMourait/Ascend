## About Ascend

This is a **fully client-side** script-like mod; it has only one feature: hold left-click to achieve infinite elytra flight.  
Please note that **this does not modify any game data** — it is based on the vanilla gliding mechanics, using a specific pitch angle to gain altitude higher than the starting point.

As for the motivation: the author fell into the void after finding an elytra without any fireworks on hand, and that's the whole story.  
Hope this helps, and thank you.
